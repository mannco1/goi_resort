# Interview Helper — Parakeet + Claude

Окно поверх всех окон, которое слушает собеседника на звонке (Zoom, Teams, Telemost, Google Meet — что угодно),
расшифровывает речь локально моделью **NVIDIA Parakeet TDT 0.6B v3** и, как только собеседник договорил вопрос,
показывает тезисы ответа от **Claude** на основе вашего резюме и вакансии.

```
Звук собеседника (WASAPI loopback) ─┐
                                     ├─► Silero VAD ─► нарезка на фразы ─► Parakeet (локально, ONNX) ─┐
Ваш микрофон ───────────────────────┘                                                                 │
                                                                                                       ▼
                    Окно-оверлей ◄── стрим подсказки ◄── Claude API ◄── «собеседник договорил?» ◄── расшифровка
```

- Распознавание полностью локальное, работает на CPU (видеокарта не нужна). Parakeet v3 понимает русский, английский и ещё 23 европейских языка, язык определяет сам.
- Пока собеседник говорит, текст появляется «вживую»; после паузы (по умолчанию 0,9 с) запускается подсказка.
- Короткие реплики вроде «угу» и рассказы о компании подсказку не вызывают — модель ответит «—», и на экране останется предыдущая.
- Ваша речь с микрофона идёт в контекст: модель знает, что вы уже сказали, и не повторяется.
- Вся расшифровка и подсказки сохраняются в `sessions/ГГГГ-ММ-ДД_ЧЧ-ММ.md` — удобно для разбора после звонка.

## Установка (Windows 10/11)

1. Поставьте **Python 3.12** с [python.org](https://www.python.org/downloads/) (галочка «Add python.exe to PATH»).
2. Распакуйте папку и запустите `setup.bat` — он создаст виртуальное окружение, поставит зависимости и скопирует `config.example.toml` → `config.toml`.
3. Получите ключ в [console.anthropic.com](https://console.anthropic.com/) и сохраните его в переменную окружения (один раз, потом перезапустите терминал):
   ```
   setx ANTHROPIC_API_KEY "sk-ant-..."
   ```
4. Заполните `profile\resume.md`, `profile\vacancy.md` и по желанию `profile\notes.md` (истории по STAR, «расскажите о себе», зарплатные ожидания). Модель опирается только на эти файлы и не выдумывает опыт.
5. Запустите `run.bat`.

При первом запуске скачаются Silero VAD (2 МБ, с GitHub) и Parakeet (int8 ≈ 0,7 ГБ, с Hugging Face) — это займёт пару минут, дальше старт за несколько секунд.

## Использование

| Действие | Как |
|---|---|
| Подсказка прямо сейчас (по последней реплике собеседника) | **F2** в окне или **Ctrl+Alt+Space** глобально |
| Пауза / продолжить слушать | **F3** или **Ctrl+Alt+P** |
| Включить/выключить автоподсказки | галочка «Авто» |
| Спросить своё (если распознавание ошиблось) | напишите в нижнее поле и нажмите Enter |
| Очистить расшифровку и подсказку | кнопка ⌫ |

**Используйте наушники.** Если звук собеседника идёт из колонок, микрофон его тоже слышит и реплики дублируются.

Проверить всё без звонка можно на любом wav-файле (16 бит PCM) — он будет играть роль собеседника:
```
run.bat --file пример_вопроса.wav
```
Только расшифровка без Claude: `run.bat --no-llm`. Список звуковых устройств: `run.bat --list-devices`.

## Настройка (`config.toml`)

Главное, что стоит подкрутить:

- **`llm.model`** — `claude-haiku-5-5` (по умолчанию) отвечает быстрее всех; `claude-sonnet-5-5` думает глубже, но дольше.
- **`llm.turn_pause_ms`** — если подсказка срабатывает, когда собеседник просто задумался, увеличьте до 1200–1500; если хочется быстрее — уменьшите до 600.
- **`audio.system_device` / `audio.mic_device`** — если звук не ловится, укажите часть имени устройства из `--list-devices`.
- **`asr.providers`** — ускорение на видеокарте:
  - любая видеокарта (DirectML): `pip uninstall onnxruntime` → `pip install onnxruntime-directml`, затем `providers = ["DmlExecutionProvider"]`;
  - NVIDIA (CUDA): `pip install onnx-asr[gpu,hub]` и `providers = ["CUDAExecutionProvider"]` (нужен установленный CUDA).
- **`asr.quantization = ""`** — полная точность модели: чуть точнее, но ~2,5 ГБ и медленнее на CPU.
- **`vad.threshold`** — если фоновый шум считается речью, поднимите до 0,6–0,7.
- **`ui.hide_from_capture = true`** — окно не попадёт в демонстрацию экрана и записи (Windows 10 2004+), полезно, если по ходу звонка шарите экран.

## Если что-то не работает

- **Статус «слушаю», но текста нет.** Собеседника не слышно в выбранном устройстве вывода. Проверьте, что звонок играет в то же устройство, что выбрано в Windows по умолчанию, или укажите `audio.system_device`.
- **Ошибка при установке PyAudioWPatch.** Чаще всего из-за слишком новой версии Python — поставьте 3.12.
- **Модель не скачивается.** Нужен доступ к huggingface.co. Можно скачать файлы вручную из `istupakov/parakeet-tdt-0.6b-v3-onnx` и указать папку в `asr.model_dir`.
- **Подсказки медленные.** Проверьте задержку в строке статуса: «распознано за X с» — это Parakeet, «подсказка за X с» — Claude. Для первого помогает int8/видеокарта, для второго — Haiku и более короткий `max_tokens`.
- **Термины распознаются с ошибками** (названия CRM, библиотек). Перечислите их в `profile/notes.md` — Claude восстановит смысл по контексту.

## Устройство кода

```
interview_helper/
  audio.py        захват WASAPI loopback и микрофона, ресемплинг в 16 кГц (soxr), wav-источник для тестов
  vad.py          Silero VAD v5 через onnxruntime, покадрово
  segmenter.py    нарезка потока на фразы: start / partial / final / discard
  asr.py          Parakeet через onnx-asr + воркер (финальные фразы в приоритете, устаревшие промежуточные выкидываются)
  coordinator.py  реплики, определение конца вопроса, запуск и отмена подсказок, лог сессии
  llm.py          промпт, резюме/вакансия в кешируемом system-блоке, стриминг Claude с отменой
  ui.py           окно-оверлей на tkinter
  main.py         запуск, горячие клавиши, фоновая загрузка моделей
```

Идеи на развитие: отдельная кнопка «подробнее» для развёрнутого ответа, разбор сессии после звонка (оценка ответов по логу из `sessions/`), режим тренажёра, где Claude сам задаёт вопросы по вакансии.
